개인정보처리방침

Hermes Personal Briefing(이하 "앱")은 개발자 본인이 자신의 Google 계정에만 사용하는 개인용 도구입니다. 본 방침은 앱이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

시행일: 2026년 10월 12일

1. 접근하는 데이터

  • Google Calendar — 일정의 제목, 시작·종료 시각, 종일 여부, 장소 유형, 참석 여부, 참석 인원 수
  • Gmail — 일정·회의·마감과 관련된 메일의 제목, 수신 일시, 발신 도메인 (메일 본문과 첨부파일은 읽지 않습니다)

2. 사용 목적

위 데이터는 사용자 본인에게 제공되는 일일 일정·업무 브리핑을 생성하는 데에만 사용됩니다.

3. 저장 및 보관

  • 브리핑 생성에 필요한 최소 요약(일정 시각, 제목, 행동 항목)만 사용자가 직접 운영하는 개인 서버에 일시 저장되며, 7일 이내에 삭제됩니다.
  • OAuth 토큰은 사용자 본인의 서버에만 암호화·권한 제한된 상태로 저장됩니다.
  • 메일 본문, 첨부파일, 참석자 이메일 주소는 저장하지 않습니다.

4. 제3자 제공

앱은 수집한 데이터를 제3자에게 판매, 공유, 양도하지 않으며 광고 목적으로 사용하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다.

6. 접근 철회

사용자는 언제든지 Google 계정 → 보안 → 제3자 앱 액세스에서 앱의 접근 권한을 철회할 수 있습니다. 철회 시 앱은 더 이상 데이터에 접근하지 않습니다.
